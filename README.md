# 海底光影舞 MVP

家庭体感游戏「海底世界」中的一个小游戏原型。玩家站在摄像头前，系统提取玩家骨骼数据，并用卡通风格的灰黑色影子角色模仿玩家动作。倒计时结束后，聚光灯像手电筒一样来回晃动，让影子角色产生跳舞般的左右移动、拉伸和残影。

## 功能

- 海底 Canvas 场景：水下光束、气泡、海草和珊瑚。
- 摄像头模式：使用 MediaPipe Pose Landmarker 提取玩家骨骼数据。
- 卡通影子角色：画面不直接呈现玩家轮廓，而是用灰黑色卡通影子角色模仿玩家动作。
- 骨骼关节表现：角色手肘、手腕、膝盖、脚踝等关节会以节点区分，体现真实骨骼驱动。
- 肢体补全：当玩家部分肢体短暂出屏或置信度不足时，会根据人体比例和上一帧状态推算合理位置，减少抽搐和消失。
- 聚光灯效果：倒计时结束后模拟手电筒/追光灯以 1 秒为周期大幅左右晃动，让影子角色产生更明显的舞动感。
- 姿态采样：跳舞阶段每 1 秒截取一次玩家骨骼姿态，采样间隔内保持上一姿态，减少实时抖动。
- 调试模式：打开后在画面右下角显示实时摄像头画面，便于确认玩家是否入镜。
- 音效反馈：3 秒倒计时后播放合成节奏音乐，舞动时触发水波音效。
- 演示模式：没有摄像头或模型加载失败时，可预览多个卡通影子角色舞动。

## 运行方式

直接用浏览器打开 `index.html`。

```text
index.html
```

摄像头模式需要浏览器授权摄像头。首次使用骨骼识别时，需要联网加载 MediaPipe CDN 资源。

如果需要单独确认模型是否能加载，可打开：

```text
index.html?modeltest=1
```

## 操作

- `开始`：请求摄像头权限并进入游戏。
- `演示模式`：不用摄像头，直接预览影子效果。
- `调试`：摄像头启动后显示或隐藏实时摄像头画面。
- `♪`：开启或关闭音乐和水波音效。

## 技术说明

这是一个单文件静态 MVP，没有构建工具和本地依赖：

- HTML/CSS/JavaScript 全部内联在 `index.html`。
- 主画面使用 Canvas 绘制。
- 骨骼识别使用 MediaPipe Pose Landmarker CDN。
- 支持最多 1~4 名玩家，每名玩家对应一个卡通影子角色。
- 影子角色由骨骼关键点驱动，不显示玩家真实摄像头画面或真实轮廓。
- 摄像头模式不会自动切换为演示模式；模型或摄像头失败时会显示状态，演示模式需要手动点击。

## 限制

- 摄像头权限在某些浏览器的 `file://` 页面上可能受限；如果无法打开摄像头，可用本地静态服务器运行。
- MediaPipe 模型加载需要网络；离线时可使用演示模式。
- 骨骼识别效果受光照、玩家距离、遮挡和多人重叠影响。
