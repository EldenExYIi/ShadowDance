# 海底光影舞 MVP

家庭体感游戏「海底世界」中的一个小游戏原型。玩家站在摄像头前舞动，系统识别人像轮廓后，将玩家裁剪成灰黑色影子并投影到海底场景中，形成随音乐舞动的光影效果。

## 功能

- 海底 Canvas 场景：水下光束、气泡、海草和珊瑚。
- 摄像头模式：优先使用 MediaPipe Selfie Segmentation 识别人像区域。
- 影子投影：将玩家人像 mask 裁剪成灰黑剪影，并渲染短残影。
- 音效反馈：3 秒倒计时后播放合成节奏音乐，舞动时触发水波音效。
- 演示模式：没有摄像头或模型加载失败时，可用鼠标/触摸预览影子舞动。
- 后备识别：人像分割模型不可用时，自动退回背景差分。

## 运行方式

直接用浏览器打开 `index.html`。

```text
index.html
```

摄像头模式需要浏览器授权摄像头。首次使用人像分割时，需要联网加载 MediaPipe CDN 资源。

## 操作

- `开始`：请求摄像头权限并进入游戏。
- `演示模式`：不用摄像头，直接预览影子效果。
- `取背景`：在人像模型不可用、退回背景差分时重新采样背景。
- `♪`：开启或关闭音乐和水波音效。

## 技术说明

这是一个单文件静态 MVP，没有构建工具和本地依赖：

- HTML/CSS/JavaScript 全部内联在 `index.html`。
- 主画面使用 Canvas 绘制。
- 人像识别使用 MediaPipe Selfie Segmentation CDN。
- 影子由人像 mask 裁剪生成，不使用姿态识别。

## 限制

- 摄像头权限在某些浏览器的 `file://` 页面上可能受限；如果无法打开摄像头，可用本地静态服务器运行。
- MediaPipe 模型加载需要网络；离线时会退回背景差分。
- 背景差分模式对光照变化和静态物体更敏感，识别精度不如人像分割。
